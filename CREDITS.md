## Windows

There is no Microsoft artwork in this repository, deliberately. Microsoft
requires a trademark licence to use the Windows logo and does not grant one for
this kind of use. The four-pane mark drawn in
`RaccoonBot/Components/PlatformBadge.swift` is plain geometry written here, not
Microsoft's logo file.
